# 🛒 BlinkIT Grocery Sales Analysis Dashboard

An interactive **Power BI Dashboard** designed to analyze grocery sales performance, product categories, outlet characteristics, and business trends using BlinkIT grocery sales data.

## 📌 Project Overview

This project focuses on analyzing grocery sales data to identify important business insights and understand sales performance across different product categories and outlet locations.

The dashboard provides an interactive view of key performance indicators (KPIs), sales distribution, outlet performance, and customer ratings to support data-driven business decisions.

## 🎯 Project Objectives

- Analyze overall grocery sales performance.
- Identify top-performing product categories.
- Understand sales distribution based on fat content.
- Compare outlet performance by size and location.
- Analyze sales trends based on outlet establishment year.
- Build an interactive dashboard for business analysis.

## 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPI creation.
- **CSV** – Dataset format.

## 📂 Dataset Information

- **Dataset:** BlinkIT Grocery Data
- **Total Records:** 8,523
- **Total Columns:** 11

### Dataset Attributes

| Column | Description |
|---|---|
| Item Identifier | Unique product identification |
| Item Fat Content | Fat content category |
| Item Type | Grocery product category |
| Item Visibility | Product visibility percentage |
| Sales | Product sales amount |
| Rating | Customer rating |
| Outlet Identifier | Unique outlet identification |
| Outlet Establishment Year | Outlet establishment year |
| Outlet Size | Outlet size category |
| Outlet Location Type | Outlet location classification |
| Outlet Type | Outlet classification |

## 📊 Key Performance Indicators

The dashboard includes the following KPIs:

1. **Total Sales** – Overall revenue generated.
2. **Average Sales** – Average sales value.
3. **Number of Items** – Distinct count of products.
4. **Average Rating** – Average customer rating.

## 📈 Dashboard Visualizations

- Total Sales by Fat Content – Donut Chart.
- Total Sales by Item Type – Bar Chart.
- Fat Content by Outlet – Stacked Column Chart.
- Sales by Outlet Establishment Year – Line Chart.
- Sales by Outlet Size – Donut Chart.
- Sales by Outlet Location Type – Funnel / Bar Chart.
- Outlet Performance – Matrix / Table.

## 🎨 Dashboard Design

The dashboard uses a BlinkIT-inspired yellow and green colour palette to provide a visually engaging and professional business intelligence experience.

- Yellow – Primary theme and highlights.
- Green – Headings and key visual elements.
- White – KPI cards and visual backgrounds.
- Dark Grey – Text and labels.

## 💡 Business Insights

The dashboard helps explore:

- Which product categories generate higher sales.
- How fat content influences sales distribution.
- Which outlet sizes contribute more to revenue.
- How outlet locations affect sales performance.
- How sales vary across outlet establishment years.
- How customer ratings relate to product performance.
