# Sales & Revenue Analysis Dashboard

## Project Overview
This Power BI dashboard analyzes sales and revenue data using the Superstore dataset.

## Features
- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Average Discount KPI
- Sales Trend by Order Date
- Top Performing Products
- Sales by Category
- Profit by Region
- Interactive Filters and Slicers

## Dataset
Superstore Dataset (CSV)

## Tools Used
- Microsoft Power BI Desktop
- CSV Dataset
